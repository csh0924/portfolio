CASE 01 BACKEND · AI PIPELINE 2024. 03 — 2024. 06

Emotion Music Diary

Emuda

감정 일기 분석 결과와 사용자 음악 취향을 결합한 개인 맞춤형 플레이리스트 추천 서비스

00 / OVERVIEW

첫 번째 팀 프로젝트
API 개발과 서비스 흐름 연결

Spring Boot 기반 REST API 개발과 데이터 구조 설계 담당. BERT 감정 분석 결과, 사용자 음악 취향, ChatGPT 추천 결과와 Spotify 음악 정보를 연결하는 백엔드 서비스 파이프라인 구축.

Period
2024. 03 — 2024. 06
Team
5명 · Backend 2명
Role
Backend Development
AI Pipeline Integration
Platform
Web · iOS WebView

01 / PRODUCT

감정 기록 및
음악 추천 경험 설계

일기 작성, 감정별 분석 결과 확인, 사용자 취향 및 감정 기반 플레이리스트 추천으로 이어지는 서비스 기능 구성.

02 / CONTRIBUTION

Backend Development
& AI Integration

백엔드 API 개발 및 외부 AI·음악 서비스 연동 담당.

01

REST API 설계

Spring Boot 기반 회원, 일기, 플레이리스트 API 구현. iOS 클라이언트 연동을 위한 DTO 및 응답 구조 표준화.

02

AI 서비스 연동

BERT 감정 분석 결과를 ChatGPT 음악 추천 입력으로 전달하고, Spotify 음악 정보 조회 및 저장 과정과 연결.

03

프롬프트 엔지니어링

감정·취향 정보 전달 방식과 추천 조건을 팀 공동으로 설계. 서버에서 처리 가능한 응답 형식을 얻도록 프롬프트 조정.

04

배포와 운영

AWS EC2 환경에 Spring 애플리케이션 배포. 환경 변수, 네트워크 포트 및 애플리케이션 로그 관리.

TECHNICAL DECISIONS

연동 과정의 문제와 설계 판단

DECISION / 01

ChatGPT 응답 형식 표준화

Problem
추천 결과의 곡명·가수·추천 사유가 일관되지 않아 서버 파싱과 Spotify 조회가 불안정한 문제
Decision
자유 형식 문장 대신 서버가 처리할 수 있는 출력 구조를 프롬프트 단계에서 제한
Applied
감정 점수와 핵심 키워드, 선호 장르를 구조화해 전달하고 음악 정보를 JSON 형식으로 반환하도록 조건 명시

DECISION / 02

iOS 클라이언트 데이터 계약

Problem
일기·감정 분석·추천 데이터가 연속으로 전달되며 화면별 필드와 오류 처리 방식이 달라질 가능성
Decision
클라이언트와 서버 사이의 필드 명세 및 성공·실패 상태를 REST API 수준에서 통일
Applied
요청·응답 DTO를 기능별로 분리하고 HTTP 상태 코드와 공통 응답 구조를 기준으로 iOS 연동

DECISION / 03

외부 API 연쇄 호출 관리

Problem
BERT 분석, ChatGPT 추천, Spotify 조회가 순차 실행되어 지연과 오류 발생 지점 파악이 어려운 구조
Decision
각 단계의 입력·출력 책임을 분리하고 다음 단계에 필요한 데이터만 전달
Applied
감정 분석 결과 정규화, 추천 결과 파싱, 음악 메타데이터 저장 단계를 구분하고 애플리케이션 로그로 처리 구간 확인

03 / SERVICE FLOW

Diary-to-Playlist
Service Flow

일기 입력, 감정 분석, 프롬프트 생성, 음악 추천으로 이어지는 전체 처리 과정.

04 / ARCHITECTURE

System
Architecture

클라이언트, Spring 서버, AI 모델 서버, 외부 API와 데이터베이스의 구성.

05 / RESULTS

Implementation Results
& Limitations

감정 분류 및 음악 추천 구현 결과와 기술적 한계.

RESULT / 01

BERT 감정 분석

한국어 일기 텍스트를 행복·분노·놀람·슬픔으로 분류하고 감정별 확률 반환. 모호하거나 복합적인 감정 표현에서 분류 정확도가 저하되는 한계 확인.

PROBABILITY ORDER[행복, 분노, 놀람, 슬픔]

RESULT / 02

감정 기반 음악 추천

분석 감정과 사용자 취향을 조합한 음악 목록 생성. 과거 청취 음악과 AI 추천 음악을 하나의 화면에서 확인하는 기능 구현.

06 / LEARNING

Technical Review
& Project Significance

BERT와 ChatGPT API를 연결한 초기 단계의 AI 활용 프로젝트. 정량적 모델 평가가 충분하지 않았으며, 복합 감정 입력에서 분류 성능이 저하되는 한계 존재.

첫 팀 프로젝트를 통해 API 계약, 역할 분담, 클라이언트 연동, 외부 AI 서비스 오케스트레이션 및 서버 배포 과정 경험. 후속 AI·컴퓨터비전 프로젝트로 확장하기 위한 개발 기반 확보.
